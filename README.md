# 梁潇的个人作品集

网站：https://lx-1203.github.io/

全栈开发、AIGC、三维建模、绘画与音乐作品展示。绘画按时间线整理。

基于 [developerFolio](https://github.com/saadpasta/developerFolio)，许可证见 LICENSE。含身份证号的证书原图不在公开仓库中。视频使用完整时长的网页播放版。

## 本地运行

```sh
npm ci
npm start
```

## 更新网站

运行 `npm run build`，将 build 目录中的文件同步到 docs，保留 docs/.nojekyll，再提交到 main 分支。GitHub Pages 从 main 分支的 docs 目录发布。
